## 实现与判据

[handoff_timing.py](../../../../next_project/core/planning/handoff_timing.py)记录提交到结果/失败/超时的完整墙钟耗时，以及提案到授权的耗时。规划与授权分别统计P95；样本不足时默认12s、2.4s，并取已测最大值与默认值中的较大者。墙钟窗口转为仿真窗口：`max(0.5, (规划P95 + 授权P95 + 0.5) × RTF P95)`。RTF来自同一节点的仿真/单调墙钟增量；暂停期间零增量不降低保守提前量，时钟回退清空RTF窗口。旧轨迹剩余安全窗口不足时记录原因并保留既有回退流程。

[observation_completion.py](../../../../next_project/core/exploration/observation_completion.py)保存小型帧凭据，不复制地图。建图器在真实射线积分后发布帧时间、该帧绑定的机体位姿、序号、地图版本和射线格数。`sensor_position`字段记录该帧绑定的机体位置以核对目标；射线建图仍从经过机体姿态变换的激光安装偏移发射点积分。执行器要求帧时间不早于持续满足终点跟踪条件的起点，帧新鲜度≤1.5s、位姿与帧时间差≤0.15s、终点位置误差<0.07m、偏航误差<0.12rad，且有效授权和邻机安全条件仍满足。跟踪丢失或安全冲突会重置到达窗口。已知视野也可由真实积分帧证明完成，不强制制造新增覆盖。运动中交接仍使用既有实际服务收益检查，不用终点帧替代未访问目标的观测。
