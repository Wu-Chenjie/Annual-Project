Gazebo在仿真197.701s确认实体圆柱移动，激光在197.800s实际命中。无人机0于198.000s撤销受阻路线，203.601s对预先缓存的不同候选取得新授权，203.800s实际执行；随后在216.000s因新地图再次撤销并重新拟合。切换备选执行期的离线团队新增已知体素为0、新增自由体素为1，真实飞行距离5.330m；后继服务另有23个团队新增已知体素，不合并计入切换收益。旧轨迹剩余参考6.325m，新授权轨迹全长13.066m，差值6.741m仅是参考路径几何代价。障碍移除ACK为222.201s。

仿真411.000s达到90%，552.500s达到95%，最终95.0110%；起飞后零接触，采样最小机距1.627m。[独立覆盖/飞行](independent-acceptance.json)、[授权协议](execution-protocol-audit.json)、[时间/收益账本](todo-audit.json)和[动态专项复核](dynamic-backup-audit.json)均通过。动态专项[原10c审计失败](dynamic-backup-audit-10c-original-fail.json)与只读10d修订同时保存；10d把再次撤销前的真实执行窗口与后继服务分开，不改变飞行策略或原始数据。完整原始传感流、命令流、轨迹及进程日志留在本工作区 `artifacts/todo-execution/candidate-10c-physical-demo-900/`，GitHub上传了录像、关键日志和审计结果；没有把这一开发专项计入预注册的80次性能样本。
