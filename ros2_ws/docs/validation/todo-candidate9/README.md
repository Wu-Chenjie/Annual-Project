# 候选9：重新冻结的单一融合飞行策略

候选8主图无故障五组配对全部完成，但固定的收尾和规划等待门槛未通过；[原始结果和只读审核历程](../todo-candidate8/README.md)保留，不并入候选9的正式结果。实验协议保留同一复杂三维地图、3机、种子900–904、运动及安全限制、95%覆盖口径和80项串行矩阵。

候选9在同一融合入口加入到达时团队承诺扣除，运动中备选在提出和最终授权时复核实际团队收益、任务归属和生命周期；父进程只立即更新障碍安全树，密集导航表交由工作进程按需建立。连续曲线质量、最多五条备选、安全预约和执行审计仍保持。它是单独的冻结飞行版本，不带运行时算法切换参数。
